# MUSIC — папки аудиорелизов

Загружай песни в папки соответствующих альбомов и EP ниже. Папки уже подготовлены — создавать их заново не нужно.

Поддерживаемые форматы: MP3, M4A, WAV, OGG.

Сохраняй оригинальные названия аудиофайлов. Если один трек встречается в нескольких релизах, пока загрузи его один раз; аудиопривязки на сайте настроим отдельно.
